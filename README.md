# 💰 Salary Prediction Web App

A Machine Learning web application that predicts salary based on user input features.
The model is deployed as an interactive web app using Streamlit.

## 🚀 Live Demo

Try the app here:
https://ankitajoseph22-salary-prediction-streamlit-app-wj3krl.streamlit.app/

## 📌 Features

* Interactive web interface for user input
* Real-time salary prediction
* Data visualization using Matplotlib
* Deployed online using Streamlit Cloud

## 🛠️ Tech Stack

* Python
* Streamlit
* Scikit-learn
* Pandas
* NumPy
* Matplotlib

## ⚙️ How to Run Locally

1. Clone the repository

```
git clone https://github.com/AnkitaJoseph22/salary-prediction-streamlit.git
```

2. Install dependencies

```
pip install -r requirements.txt
```

3. Run the app

```
streamlit run app.py
```
